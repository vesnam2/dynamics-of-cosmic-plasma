# Dynamics of Cosmic Plasma – Programming Projects

This repository contains a collection of programming projects completed as part of the
*Dynamics of Cosmic Plasma* course. The projects focus on numerical modeling and computational
analysis of physical processes relevant to cosmic and astrophysical plasmas.

## Course Overview

The course covers theoretical and computational aspects of plasma dynamics in astrophysical
contexts, with emphasis on:
- Magnetohydrodynamics (MHD)
- Plasma instabilities
- Wave propagation in plasmas
- Numerical methods applied to plasma physics

As part of the pre-exam requirements, four independent programming projects were completed.


Each project directory contains:
- source code 
- generated figures and visualizations 

---

## Projects Summary

### Project 1
Numerical implementation and analysis of fundamental plasma equations, focusing on basic
plasma behavior under simplified assumptions.

### Project 2
Simulation of wave propagation in a plasma medium, including visualization of relevant
physical quantities.

### Project 3
Study of plasma instabilities using numerical methods, with emphasis on stability criteria
and time evolution.

### Project 4
Advanced numerical modeling of plasma dynamics, combining theoretical insight with
computational techniques.



## Tools and Technologies

- Programming language(s): Python 
- Numerical methods for differential equations
- Data visualization and analysis libraries
